| 항목 | 내용 |
|---|---|
| 프로젝트명 | DemoPort |
| 목적 | 개발자 안가영의 역량과 작업물을 소개하는 개인 프로필 웹사이트 |
| 개발자 | 안가영 |

## 2. 배경 및 목표

### 배경
바이브코딩(AI와 협업하는 코딩)으로 Python, HTML5 기반의 작은 프로젝트와 게임(뱀 게임, 테트리스 등)을 만들어 왔다. 이 결과물을 한곳에서 보여주고 연락받을 수 있는 공간이 필요하다.

### 목표
1. 방문자가 10초 안에 "누구이고 무엇을 하는 개발자인지" 파악할 수 있다.
2. 작업물을 직접 실행해 볼 수 있는 데모 링크를 제공한다.
3. 이메일로 쉽게 연락할 수 있다.

### 비목표 (이번 범위 제외)
- 회원가입/로그인, 백엔드 서버, 데이터베이스
- 블로그 CMS, 댓글 기능
- 다국어 전환 (1차는 한국어만)

## 3. 타깃 사용자

| 사용자 | 니즈 |
|---|---|

| 협업·외주 제안자 | 작업 스타일과 연락 방법 확인 |
| 동료 개발자/학습자 | 프로젝트 예시와 바이브코딩 활용 사례 참고 |

## 5. 비기능 요구사항

| 항목 | 기준 |
|---|---|
| 반응형 | 모바일(360px)~데스크톱(1440px) 레이아웃 깨짐 없음 |
| 성능 | 외부 라이브러리 없이 HTML/CSS/JS만 사용, 초기 로드 1MB 이하 |
| 접근성 | 시맨틱 태그, 이미지 alt, 명도 대비 WCAG AA, 키보드 탐색 가능 |
| 호환성 | 최신 Chrome, Edge, Safari, Firefox |
| SEO | title, meta description, Open Graph 기본 태그 |
| 테마 | 다크/라이트 자동 대응 (`prefers-color-scheme`) |

## 6. 기술 스택

- **마크업:** HTML5 (시맨틱 태그)
- **스타일:** CSS3 (Flexbox/Grid, CSS 변수, 미디어 쿼리)
- **동작:** 바닐라 JavaScript (스무스 스크롤, 모바일 메뉴)
- **배포:** GitHub Pages 또는 정적 호스팅

## 7. 디자인 방향

- 톤: 깔끔하고 현대적인 미니멀 스타일, 개발자 포트폴리오다운 차분함
- 색상: 어두운 배경(#0f1420 계열) + 포인트 컬러 1개(블루 #4f7cff 계열), 라이트 모드 대응
- 폰트: 본문은 시스템 폰트(Segoe UI, Malgun Gothic), 코드/태그에는 고정폭 폰트
- 레이아웃: 카드 기반, 넉넉한 여백, 섹션별 명확한 구분
